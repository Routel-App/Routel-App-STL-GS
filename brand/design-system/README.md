# STL Container System — design assets

The living design system (tokens, brand book, components) is published at:
https://claude.ai/artifact/XNj9n3gKRJUtxG68DptwD2

This folder keeps the source files used by the site:

- `illustrations/` — side-view vectors: containers (20ft, 40ft, HC, reefer, flat rack, ISO tank), truck with container, container ship, reach stacker, STS crane, tug, cargo plane.
- `icons/` — STL cargo icons, 32px grid, 1.75 stroke, petrol with one coral detail.
- `patterns/` — corrugated wall tile and corner casting.
- `tokens.json` — the design tokens (colours light/dark, type, spacing, radius, shadow, container module).
